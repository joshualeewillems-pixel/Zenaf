**Purpose:** Inventory of AI-touching flows vs the client substrate (`frontend/src/ai-actions/`): `AiActionTrace`, coarse `action_kind`, optional `action_intent`, `AiActionResultPanel`, in-memory traces only.

**Rules for this doc:** No new `AiActionKind` values; proposed mappings use only `field_text_rewrite` \| `suggestion_batch` \| `structured_evaluation`. Proposed `action_intent` strings are **suggested** labels for adoption (snake_case); not an enum in code until wired.

**Legend — user outcome:** **Partial** = apply/dismiss (or equivalent) updates trace for some paths only; **No** = trace absent or outcome stays `none` / not pushed.
