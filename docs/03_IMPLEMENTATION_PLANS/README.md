# Implementation plans (`03_IMPLEMENTATION_PLANS`)

This folder holds **bounded implementation plans** and **cleanup proposals**: concrete next steps, checklists, and hardening notes.

- Docs here describe **intended next work**, not canonical as-built truth.
- After work ships, update **`docs/01_TRUTH/`** (or **`ACTIVE_VS_PLANNED.md`**) as appropriate, then **archive or retire** the plan.
- **Do not treat** these plans as **source of truth** for product or runtime behavior.
