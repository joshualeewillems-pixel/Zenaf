# Reference (`04_REFERENCE`)

This folder holds **durable reference docs**: specs, field/tab maps, and feature lookup material.

- These docs help readers understand **shapes, tabs, entities, and behavior details**.
- Reference docs are **not** the same as **canonical truth** (`docs/01_TRUTH/`) or **active design** (`docs/02_ACTIVE_DESIGN/`).
- If **runtime behavior** changes, update **truth** docs and any **relevant reference** docs here.

**Examples:** `VISION_EXECUTION_TABS_REFERENCE.md` (VE tabs/fields). The **Vision map** (React Flow + sand + triad) is documented under **truth** as **`docs/01_TRUTH/VISION_MAP_AND_ZEN_PROJECTION.md`** (not a tab reference).
