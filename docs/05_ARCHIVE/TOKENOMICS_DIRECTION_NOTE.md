## Status

The tokenomics layer (Integration Artifacts / “Fruit”) is:

- **Conceptually defined**
- **Charter-aligned**
- **Partially scaffolded** (arc detection lab)
- **Not active** in product or user flows

No economic behavior is currently live or implied in the product.

---

## What is already true

- **Arc detection v0.1 exists as a lab interpretation layer**
  - Uses `execution_flow_reading` + VE state
  - Produces `arc_detection_candidates`
  - Explicitly **non-authoritative** (see [../02_ACTIVE_DESIGN/ARC_DETECTION_FIXTURE_SPEC.md](../02_ACTIVE_DESIGN/ARC_DETECTION_FIXTURE_SPEC.md))

- **Mint policy is defined but not operational**
  - Arc = currency unit (structure over time)
  - Stylization + provenance = co-authored layer
  - Utility = probabilistic, not causal

- **Core axiom is enforced**

  > Vitality ≠ value

---

## What is NOT yet true

- No artifact ledger (`integration_artifacts`) in production
- No utility/accrual system (`artifact_utility_signals`)
- No minting UI or user-facing artifact objects
- No economic incentives or token flows
- No guarantee that arc detection corresponds to meaningful real-world transformation

---

## System constraints (must remain true)

- Tokenomics must **never** operate on self-report alone
- All artifacts must be **derived** from VE + judgment evidence
- The system must **not** claim objective personal growth
- Economic value must **not** attach to activity, verbosity, or completion alone
- All reuse/utility must remain **system-mediated** and **non-performative**

---

## Next activation condition

Tokenomics work should resume only when:

1. Arc detection produces **consistently meaningful** candidates on **real** user data
2. `execution_flow_reading` **density** is sufficient across normal product usage
3. **Trace + identity + commit** layers are fully charter-consistent
4. At least one real arc has been:
   - detected
   - reviewed
   - accepted
   - and felt to be “true enough” by a **human** user

Until then:

> Tokenomics remains a **defined future layer**, not an active system concern.

---

## Trajectory (when resumed)

When reactivated, progression should be:

1. Arc candidates → human review loop
2. Stable accepted arcs → minimal artifact persistence
3. Private artifact library (no sharing)
4. System-mediated reuse (no marketplace)
5. Utility signal experimentation (non-causal, probabilistic)
6. Only then consider any form of value accrual

---

## Current directive

> **Do not build tokenomics features.**

Continue focusing on:

- coordination signal quality
- execution truth
- trace completeness
- identity consistency

---

## Framing

This is not abandoning tokenomics. It is **cold storage with instructions for resurrection**: the vision stays documented; charter and policy stay locked; implementation stays parked until activation conditions are met.

When prioritizing work, ask **what makes the system correct today**, not **how this eventually becomes a full economy**.
