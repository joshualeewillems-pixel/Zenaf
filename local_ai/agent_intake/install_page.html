Send to Zenaf

One tap on any ChatGPT or Claude share page sends the conversation to your Zenaf intake — no highlighting, no copy/paste.

Send to Zenaf ← drag to bookmarks bar (desktop)

iPhone (Safari)

  1. Copy the code below (tap the box, Select All, Copy).
  2. Bookmark any page, then edit the bookmark: rename to Send to Zenaf.
  3. Delete the bookmark's URL, paste the copied code, Save.
  4. On a share page: tap the address bar, type Send to Zenaf, tap the bookmark.

Android (Chrome)

  1. Copy the code below.
  2. ⋮ → bookmark this page, edit it: rename to Send to Zenaf, replace URL with the code.
  3. On a share page: tap the address bar, type Send to Zenaf, tap the bookmark.
First run asks for your Zenaf URL (already set to staging). It's remembered after that.
