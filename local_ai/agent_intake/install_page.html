Send to Zenaf

One tap on any ChatGPT or Claude conversation sends it to your Zenaf intake — sorted into strands, mined for projects. No copy/paste.

iPhone — iOS Shortcut (recommended)

Bookmarklets don't run on iPhone Safari. The Shortcut uses Apple's supported path and works every time. One-time setup, then one tap per conversation.
  1. Open the Shortcuts app, tap + (top right).
  2. Tap Add Action, search Run JavaScript on Web Page, add it.
  3. Delete the sample code in that action, paste this instead: 
    // "Send to Zenaf" — iOS Shortcut JavaScript (Run JavaScript on Web Page)
// Paste this into the Shortcut's JavaScript action. It extracts the
// conversation and calls completion() with a dictionary; the next
// Shortcut action POSTs it to Zenaf via Get Contents of URL.

(function () {
  var nodes = document.querySelectorAll('[data-message-author-role]');
  var out = [];
  for (var i = 0; i < nodes.length; i++) {
    var n = nodes[i];
    var role = n.getAttribute('data-message-author-role');
    var label = role === 'user' ? 'USER' : role === 'assistant' ? 'ASSISTANT' : String(role).toUpperCase();
    var text = (n.innerText || '').trim();
    if (text) out.push(label + ': ' + text);
  }
  var transcript;
  if (out.length) {
    transcript = out.join('\n\n');
  } else {
    var main = document.querySelector('main') || document.querySelector('article') || document.body;
    transcript = ((main && main.innerText) || '').trim();
  }
  completion({
    url: location.href,
    title: document.title || 'shared conversation',
    transcript: transcript.slice(0, 60000)
  });
})();
  4. Tap + below it, search Get Contents of URL, add it.
  5. In that action: tap URL, enter https://zenaf-staging.fly.dev/agents/connect/share-text. Tap Show More, set Method to POST.
  6. Tap Headers → Add new: Key Content-Type, Value application/json.
  7. Tap Request Body → JSON, enter: 
    {
  "url": "Shortcut Result",
  "title": "Shortcut Result",
  "transcript": "Shortcut Result"
}
    Tap each "Shortcut Result" → choose Select Variable → Shortcut Result → then pick url, title, transcript respectively.
  8. Tap +, add Show Result. Set it to the Contents of URL variable.
  9. Tap the shortcut name at top, rename to Send to Zenaf.
  10. Tap i at the bottom → enable Show in Share Sheet.

To use: on any ChatGPT/Claude conversation in Safari, tap Share → Send to Zenaf. The agent appears in your Zenaf review queue.

Desktop — Browser Extension

Fully automatic: install the Zenaf Renderer extension and it picks up render jobs on its own — no taps per conversation. Source at local_ai/agent_intake/extension/ in the Zenaf repo: open chrome://extensions, enable Developer mode, Load unpacked, select the folder, then set your Zenaf URL in its Options page.
